2. TravelEase – Sistema de Reservas (Java)

Aplicación de consola en Java para gestionar reservas de vuelos y alquiler de vehículos. Permite:

  • Reservar vuelos: verifica disponibilidad, asigna asientos y confirma el pago.
  • Alquilar vehículos: comprueba disponibilidad de vehículos, procesa el pago y registra la reserva.

Tecnologías: Java, Java Collections (List, Date), paquete personalizado Reservas, programación orientada a objetos.
